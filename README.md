# CCXP22 — Reviva o Épico

Landing page responsiva em homenagem à CCXP22, com contagem regressiva (e, após a
data do evento, contagem de tempo decorrido) até/desde 01 de dezembro de 2022.

🔗 **Deploy:** https://kelbaker.github.io/Countdown-CCXP-Responsivo/

## Stack

- HTML5
- CSS3 (layout responsivo, sem framework)
- JavaScript (Vanilla, sem dependências)

## Funcionalidades

- Contagem regressiva em tempo real (dias/horas/minutos/segundos)
- Após a data do evento, o contador continua rodando e a legenda muda para indicar
  que o evento já ocorreu
- Layout responsivo (desktop e mobile)
- Seção de ingressos por dia do evento

## Como rodar localmente

Não há build step — é HTML/CSS/JS puro.

```bash
git clone https://github.com/KelBaker/Countdown-CCXP-Responsivo.git
cd Countdown-CCXP-Responsivo
```

Depois é só abrir o `index.html` no navegador (ou usar a extensão Live Server do VS Code).
